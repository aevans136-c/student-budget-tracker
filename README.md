# student-budget-tracker
A Python application that tracks student expenses, checks monthly budgets, and exports budget reports to CSV.
Features

Calculates total expenses and remaining balances.
Allows users to enter custom expense categories.
Checks expenses against a monthly spending budget.
Evaluates whether a savings goal is achievable.
Exports budget summaries to a CSV file.

Technologies

Python
CSV
Lists and loops
Conditional statements
File handling

How to Run

Install Python 3.
Download Student_Budget_Tracker.py.
Open a terminal in the file's folder.
Run:
python3 Student_Budget_Tracker.py

What I Learned

Through this project, I practiced using Python variables, loops, lists, conditional logic, calculations, and file handling to solve a practical budgeting problem.
